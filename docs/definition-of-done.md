# Definition of Done (DoD) - Team 05

ทุกฟีเจอร์หรือ Issue จะถือว่า "เสร็จสมบูรณ์ (Done)" ก็ต่อเมื่อผ่านเงื่อนไข 5 ข้อดังต่อไปนี้:

1. **Acceptance Criteria Met:** ฟีเจอร์ทำงานได้จริงตามเงื่อนไข (Acceptance Criteria) ครบทุกข้อที่ระบุไว้ใน Issue
2. **Peer Reviewed & Approved:** โค้ดต้องถูกส่งผ่าน Pull Request (PR) บน GitHub และได้รับการ Review/Approve จากเพื่อนในทีมอย่างน้อย 1 คนก่อนกด Merge
3. **UI/UX & Responsive:** หน้าจอแสดงผลได้ถูกต้องตามสไตล์ Minimalist ที่ทีมออกแบบไว้ (เช่น การใช้ Tailwind CSS/Shadcn) และรองรับการแสดงผลบนหน้าจอมือถือได้อย่างสมบูรณ์
4. **Build Pass & No Breaking Changes:** โค้ดที่เพิ่มเข้ามาใหม่ต้องสามารถรัน Build ผ่านโดยไม่มี Error ร้ายแรง และไม่ทำให้ระบบหรือฟีเจอร์เก่าพัง
5. **AI Usage Transparency:** หากมีการใช้ AI ช่วยเขียนโค้ดหรือออกแบบฟีเจอร์ ต้องมีการเขียนระบุที่มาและวิธีการใช้งานอย่างโปร่งใสใน PR Description เสมอ
