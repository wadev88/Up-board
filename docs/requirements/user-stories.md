# User Stories #

---

## 📱 1. กลุ่มผู้ใช้งาน: อานนท์ สายรุ้ง (Campus User / นิสิต)

### US1.1: การแจ้งซ่อมแบบรวดเร็ว (One-Tap Report & Auto GPS)
* **As a:** นิสิตผู้ใช้งานแคมปัส
* **I want to:** ถ่ายภาพจุดชำรุดและกดส่งเรื่องได้ทันที โดยระบบทำการปักพิกัด GPS ให้อัตโนมัติ
* **So that:** ฉันสามารถรายงานปัญหาความไม่ปลอดภัยได้ในเวลาไม่ถึง 5 วินาทีโดยไม่ต้องเสียเวลาเรียนกรอกฟอร์มซับซ้อน

### US1.2: การปกป้องความเป็นส่วนตัว (Auto Privacy Blur)
* **As a:** นิสิตผู้ใช้งานแคมปัส
* **I want to:** ให้ระบบเบลอภาพใบหน้าบุคคลหรือสิ่งไม่พึงประสงค์ในพื้นหลังให้อัตโนมัติก่อนส่งเรื่อง
* **So that:** ฉันสามารถแชร์ข้อมูลสภาพแวดล้อมได้อย่างสบายใจโดยไม่ละเมิดความเป็นส่วนตัวของผู้อื่น

### US1.3: การติดตามสถานะเรียลไทม์ (Real-time Status Notification)
* **As a:** นิสิตผู้ใช้งานแคมปัส
* **I want to:** ได้รับ Push Notification ยืนยัน Tracking ID ทันที และได้รับการอัปเดตเมื่อมีการเข้าซ่อมแซม
* **So that:** ฉันรับรู้ความคืบหน้าของปัญหาที่แจ้งโดยไม่ต้องคอยโทรสอบถามหรือเดินทางไปตามเรื่องเอง

## 👩‍🔧 2. กลุ่มผู้ใช้งาน: อาทร ศรีสุข (Facilities & Environment Officer / เจ้าหน้าที่จัดสรรงาน)

### US2.1: แดชบอร์ดกลางและการจัดลำดับความสำคัญ (Central Dashboard & AI Prioritization)
* **As a:** เจ้าหน้าที่ฝ่ายซ่อมบำรุงและสิ่งแวดล้อม
* **I want to:** ดูแดชบอร์ดรวมเคสแจ้งซ่อมที่ระบบ AI ประเมินและจัดลำดับความสำคัญ (เช่น High Hazard) ให้อัตโนมัติ
* **So that:** ฉันสามารถมอบหมายงานด่วนให้ช่างที่รับผิดชอบโซนได้ทันทีเพื่อป้องกันอุบัติเหตุ

### US2.2: ระบบแจ้งเตือนผู้แจ้งอัตโนมัติ (Automated Status Notification)
* **As a:** เจ้าหน้าที่ฝ่ายซ่อมบำรุงและสิ่งแวดล้อม
* **I want to:** ให้ระบบส่งการแจ้งเตือนสถานะกลับไปยังผู้แจ้งโดยอัตโนมัติเมื่อมีการมอบหมายงานหรือแก้ปัญหาเสร็จสิ้น
* **So that:** ลดข้อร้องเรียนซ้ำซ้อน สร้างการสื่อสารที่โปร่งใส และช่วยประหยัดเวลาให้ฉันมี Work-Life Balance ดีขึ้น

### US2.3: บันทึกข้อมูลเพื่อการวางแผนเชิงป้องกัน (Predictive Maintenance Logging)
* **As a:** เจ้าหน้าที่ฝ่ายซ่อมบำรุงและสิ่งแวดล้อม
* **I want to:** บันทึกประวัติและข้อมูลการซ่อมบำรุงเข้าฐานข้อมูลกลางโดยอัตโนมัติ
* **So that:** สามารถนำข้อมูลมาใช้วางแผนบำรุงรักษาเชิงป้องกัน (Predictive Maintenance) และลดภาระการคีย์ข้อมูลซ้ำซ้อนด้วยมือ

## 🛠️ 3. กลุ่มผู้ใช้งาน: วิชัย ช่างทอง (Field Maintenance Technician / ช่างหน้างาน)

### US3.1: รายละเอียดงานซ่อมและอุปกรณ์แนะนำ (Detailed Job Info & Tool List)
* **As a:** ช่างซ่อมบำรุงหน้างาน
* **I want to:** ดูรูปถ่าย พิกัดสถานที่อย่างแม่นยำ และรายการอุปกรณ์แนะนำบนแอปพลิเคชันมือถือ
* **So that:** ฉันสามารถเบิกเครื่องมือได้ถูกต้องและเดินทางไปแก้ไขปัญหาได้จบในรอบเดียว

### US3.2: อัปเดตสถานะและแนบรูปหลังซ่อม (Mobile Status Update & Photo Proof)
* **As a:** ช่างซ่อมบำรุงหน้างาน
* **I want to:** กดอัปเดตสถานะ "กำลังดำเนินการ / ซ่อมเสร็จสิ้น" และแนบรูปภาพหลังซ่อมผ่านปุ่มขนาดใหญ่บนสมาร์ทโฟน
* **So that:** ฉันสามารถส่งงานได้รวดเร็วหน้างานโดยไม่ต้องเดินทางกลับมาเซ็นเอกสารกระดาษที่สำนักงาน

### US3.3: โหมดทำงานแบบออฟไลน์ (Offline Data Syncing)
* **As a:** ช่างซ่อมบำรุงหน้างาน
* **I want to:** ให้แอปพลิเคชันบันทึกข้อมูลการปิดงานไว้ในเครื่อง (Local) เมื่ออยู่ในจุดอับสัญญาณ และทำการ Sync ขึ้นระบบเมื่อมีอินเทอร์เน็ต
* **So that:** การบันทึกและอัปเดตสถานะงานหน้างานไม่หยุดชะงักแม้ต้องทำงานในอาคารเก่าหรือจุดที่สัญญาณแย่

## 👨‍💼 4. กลุ่มผู้ใช้งาน: สมชาย มั่นคง (System Administrator / ผู้ดูแลระบบ)

### US4.1: ระบบ Admin Console & Real-time Analytics
* **As a:** ผู้ดูแลระบบสารสนเทศ
* **I want to:** ตรวจสอบ Uptime, ประสิทธิภาพ API และสถานะการส่ง Push Notification ผ่าน Admin Console
* **So that:** สามารถดูแลระบบให้เสถียร มี Uptime สูงสุด (99.9%) และพร้อมใช้งานตลอด 24 ชั่วโมง

### US4.2: ระบบคัดกรองเนื้อหาอัตโนมัติ (Auto-Moderation & Anti-Spam)
* **As a:** ผู้ดูแลระบบสารสนเทศ
* **I want to:** มีระบบ Auto-Moderation คอยตรวจจับ ตรวจสอบคำหยาบ และบล็อกโพสต์สแปมก่อกวนให้อัตโนมัติ
* **So that:** ลดภาระการนั่งคัดกรองเนื้อหาด้วยมือและจัดการรายงานเท็จได้อย่างทันท่วงที

### US4.3: การจัดการข้อมูลและทรัพยากรอัตโนมัติ (Automated Storage & Data Cleanup)
* **As a:** ผู้ดูแลระบบสารสนเทศ
* **I want to:** ตั้งค่า Cron Job สำหรับลบไฟล์ภาพชั่วคราวที่ไม่เกี่ยวข้องและจัดการ Database Logs อัตโนมัติ
* **So that:** ระบบสามารถประหยัดพื้นที่จัดเก็บข้อมูลบนคลาวด์และคงความเร็วในการประมวลผลไว้ได้เสมอ
