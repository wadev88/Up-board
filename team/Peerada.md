# Broken Window ที่เคยเจอ
* **(1) Window คืออะไร:** ตอนทำโปรเจกต์ที่ต้องต่อระบบเข้ากับ Backend/AI เคยฮาร์ดโค้ด URL (http://localhost:5000) กับ Logic จัดการ Data Stream ยัดไว้ใน Component หน้าบ้านตรงๆ แถมใส่ any ละเลย Type และไม่ได้ดัก Error ไว้ เพราะตอนนั้นรีบปั่นให้ระบบแสดงผลได้ทัน
* **(2) ผลกระทบ:** พอระบบเริ่มมีหลายหน้าและเพื่อนในทีมต้องดึงข้อมูลแบบเดียวกัน เพื่อนก็ใช้วิธีก๊อปปี้โค้ดชุดนั้นไปแปะซ้ำๆ ทั่วทั้งโปรเจกต์ พอถึงเวลาเปลี่ยน Port หรือเซิร์ฟเวอร์หลุด ระบบก็พังระงมทั้งโปรเจกต์ แถมไล่แก้ทีละจุดยากมากเพราะโค้ดผูกกันมั่วไปหมด
* **(3) ถ้าแก้ทันทีจะป้องกันอะไร:** ถ้าแยก Service Layer ทำ Config ผ่าน .env และจัดการ Data Type ให้เรียบร้อยตั้งแต่แรก เพื่อนร่วมทีมก็จะมี Template ที่ดีไปใช้ต่อ ไม่เกิดโค้ดขยะซ้ำซ้อน และไม่ต้องเสียเวลาหลายวันมารื้อแก้อะไรเดิมๆ
