# Broken Window ที่เคยเจอ
* **(1) Window คืออะไร:** ข้อผิดพลาดโค้ดที่จัดวางไม่เป็นระเบียบ บั๊กเล็กๆ เอกสารไม่อัปเดต ถูกปล่อยทิ้งไว้โดยไม่มีใครสนใจแก้ไข
* **(2) ผลกระทบ:** เมื่อสมาชิกในทีมเห็นว่ามีโค้ดมั่วๆ ถูก Commit ขึ้นระบบได้ ก็จะเริ่มมักง่ายและลดมาตรฐานการเขียนโค้ดของตัวเองตามไปด้วย
* **(3) ถ้าแก้ทันทีจะป้องกันอะไร:** การแก้จุดเล็กๆใช้เวลาแค่ไม่กี่นาที ป้องกันไม่ให้มันบานปลายกลายเป็นงานซ่อมใหญ่ที่ต้องใช้เวลาเป็นสัปดาห์
