ข้อความจากระบบ

ระบบจะตรวจสอบเวลาของโพสต์และซ่อนออกจากหน้าฟีดเมื่อครบ 24 ชั่วโมง

ลำดับการทำงานของระบบ

ขั้นตอนการทำงานของระบบหลังบ้าน

1. User creates post
2. System saves created_at
3. System calculates expires_at = created_at + 24 hours
4. Post appears on normal feed
5. System checks time periodically
6. If current time ≥ expires_at
7. Change status to Hidden / Expired
8. Remove from normal feed
9. Admin can still view post history
